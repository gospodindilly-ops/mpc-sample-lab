# Своя прошивка для MPC Sample: карта функций и этапы

Источник списка функций: MPC Sample User Guide v1.3.0 (RevA), разделы Features и Operation.
Реализация независимая: по описанию поведения, без кода, звуков и графики Akai.
Работает поверх штатной ОС, из RAM, при остановленном `ac50.service`: прошивка и флеш не меняются.
Как устроена прошивка (слои, потоки, модель данных, 16 треков) — в [architecture.md](architecture.md). Сверх руководства MPC Sample в план входят 16 треков со своим секвенсором у каждого и функции MPC 3 (§5).

Обозначения: ✅ готово; 🟢 этап 1 (`firmware/`); 🟡 следующие этапы; ⚪ сначала нужно исследование.

## 1. Что уже есть из железа (проверено)
Панель (пэды с силой удара и aftertouch, 24 кнопки, 3 ручки, MAIN VOLUME, фейдер, энкодер) ✅ ·
подсветка кнопок и RGB-пэдов ✅ · звук I2S 44,1 кГц, задержка как у штатного приложения ✅ ·
экран 320×240 через DRM без потерь звука ✅ · загрузка WAV с SD ✅ · приоритет реального времени ✅.

## 3. Этап 1 — что в `firmware/`
- **Звуковой движок:** 32 стерео-голоса, линейная интерполяция высоты тона, огибающие, Mono/Poly, группы глушения, Loop/Reverse/Note On, короткое затухание при обрыве голоса — повторный удар, mute-группа, STOP (без щелчков), панорама балансом (в центре без потерь), мягкое ограничение на выходе.
- **Модель проекта:** 8 банков × 16 пэдов, параметры по руководству.
- **Управление:** все кнопки этапа 1, SHIFT-функции, PAD BANK, MUTE, ERASE, страницы B1/B2/B3, K1–K3 со Scaled takeover, фейдер (Pad Volume, Pickup), энкодер и −/+.
- **Экран** — по снимкам руководства: вкладки B1–B3 с чёрточками страниц, жёлтая строка с треком, пэдом, именем сэмпла и значками Note On / Reverse / Loop / 16 Levels, стерео-форма волны с линейками, полосами громкости и панорамы, луп-точкой (на Amp Env — с цветной огибающей), ряд K1–K3 с полосами и значок SHIFT. SAMPLE + энкодер — сетка 16 треков.
- **Подсветка:** яркие — активные функции, тусклые — доступные, выключенные — недоступные (как в руководстве).

## 4. Чего не хватает для дальнейших этапов (исследование)
1. Горят ли значки батареи и зарядки без штатного приложения (поведение — по руководству).
2. Каким сообщением панели выдаётся импульс SYNC OUT (поведение — по руководству).
3. Есть ли в протоколе панели REC GAIN (вероятно, это аналоговая ручка без МК).
4. Цвета каналов двухцветных светодиодов (A/B).

## 5. Сверх руководства: 16 треков и функции MPC 3
Источник: MPC Standalone OS User Guide v3.4 и MPC Software v3.9 Beta User Guide (оглавление). Порядок работ — в [architecture.md](architecture.md), §10.

### Треки и секвенсор
| Функция | Этап | Комментарий |
|---|---|---|
| **16 треков, у каждого своя длина в секвенции** (Length в долях, как в MPC 3); общий только темп | 🟢 | главное расширение; штатная прошивка показывает один трек. Типы трека: Drum, Sample (по нотам), Audio, MIDI. Трек выбирается SAMPLE + энкодер, тип — K1, длина — K2 в сетке треков. На MPC не проверено |
| Drum-трек полностью: один сэмпл на пэд, 2 фильтра, 2 LFO, 3 огибающие, mod matrix | 🟡 | структура как в проекте штатной прошивки |
| Sample-трек по нотам: один сэмпл или зоны по нотам, Key Ranges, пэды играют ноты по ладу | 🟡 | как Keygroup в MPC |
| Audio-трек: длинная запись в регионах секвенции, Warp под темп | 🟡 | тип и экран есть; запись — с Sample Record, проигрывание — с секвенсором; стриминг с диска |
| MIDI-трек: пэды и события наружу через External (TRS) или USB, канал 1–16 | 🟡 | пэды уже шлют ноты (A01 = C1); порты ищутся по имени в /proc/asound, на устройстве не проверено |
| Next Sequence: смена секвенции на конце, со следующего такта или сразу | 🟡 | на конце — 🟢 (как в руководстве MPC Sample); со следующего такта и сразу — позже |
| Song Mode, Arrange (линейная аранжировка) | 🟡 | Arrange — упрощённый вид |
| Размер такта и темп, меняющиеся по ходу секвенции | 🟡 | пока один темп на секвенцию (или общий) и один размер на проект, как в MPC Sample |
| Step Sequencer | 🟡 | пэды как 16 шагов |
| Grid, List Editor | 🟡 | упрощённые виды под 320×240 |
| Track Mute, Pad Mute, Solo | 🟡 | Track Mute (MUTE в Sequence Mode, пэды — треки) и Pad Mute — 🟢; Solo, группы и mute по секвенциям — позже |
| Автоматизация: глобальная и по трекам, запись и правка | 🟡 | |
| Humanize, Pitch Quantization, Generate Random Events, Convert To Progression, Note Mapping | 🟡 | |
| Pad Perform (лады, аккорды, прогрессии), арпеджиатор | 🟡 | |

### Чего не будет
| Функция | Почему |
|---|---|
| Сторонние плагины VST3 / AU | устройство на Linux/ARM |
| Плагины и эффекты AIR (Bassline, Electric, Hype, TubeSynth, DrumSynth, Mellotron, Solina, Odyssey), контент MPC Oscillators | чужой код и звук: только свои инструменты и эффекты |
| Треки CV, Synth, Plugin | решено: типов четыре — Drum, Sample (по нотам, как Keygroup), Audio, MIDI |
| Клипы (Clip Launch, Clip Matrix из MPC 3) | решено 2026-10-23: не нужны; своя длина трека даёт независимые циклы |
| Слои 2–8 на пэде | решено 2026-10-23: один сэмпл на пэд, как у MPC Sample |
| XYFX, Touch FX, Q-Link Edit, Performance Controls | на MPC Sample нет XY-пэда, сенсорной полосы и ручек Q-Link |
| Выходы 3/4 | физически их нет; полоса в файле проекта хранится только ради совместимости |
| Активации, профиль inMusic, облако, Ableton Link | нет сети (Wi-Fi нет), лицензии не трогаем |
